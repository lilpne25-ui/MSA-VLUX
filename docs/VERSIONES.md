# Versionado MSA-VLUX

Distribuciones acumulativas; la V5 principal contiene las capacidades de V4.1 y V4.2. Los ZIP preservan la edición entregada para cada versión. V4.0.0-rc3 es archivo histórico, no la distribución recomendada.

- **V4.1.0:** ledger de eventos y hashes, autoevaluación con criterios verificables, tests sintéticos negativos y utilidades de diagnóstico.
- **V4.2.0:** handoff portable con manifestación y verificación, importación conservadora, límites para adjuntos, delegación y revisión estructurada.
- **V5.0.0:** comparación baseline/candidato/holdout, política de no regresión, propuestas de mejora y revisión humana obligatoria.

Las métricas demostradas en `docs/VALIDACION.md` son pruebas locales con datos sintéticos, no mediciones de agentes reales. Los tags Git serán publicados solo después de comprobar sus destinos.
