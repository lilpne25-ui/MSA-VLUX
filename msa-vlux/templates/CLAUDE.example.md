# Política MSA genérica para Claude Code / Cloud

Si se invoca MSA-VLUX, leer `SKILL.md`, ejecutar preflight y cargar solo los módulos relacionados. Declarar la versión y la disponibilidad real de roles, sandbox y herramientas. Guardar expediente `.msa` local y, en entornos efímeros, entregar un handoff verificado antes de finalizar. No atribuir autonomía ni seguridad a instrucciones escritas; no publicar cambios ni operar con secretos sin autorización. No reemplazar instrucciones existentes del usuario por esta plantilla.
